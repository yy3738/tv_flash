# 以无障碍服务作为截图与输入注入的基础

## 背景
需要在电视上无人值守地截图并注入点击。可选 MediaProjection（屏幕采集）或无障碍服务（AccessibilityService）。

## 决定
以无障碍服务为核心：用 takeScreenshot 截图、dispatchGesture 注入点击 / 滑动、performGlobalAction 触发返回 / 主页等全局动作。

## 理由
- MediaProjection 每次建立采集会话都需要系统弹窗授权（Android 14 后更严），与“开机自启、无人值守”根本冲突，且带常驻录制提示。
- 无障碍服务一次启用后重启仍有效，支持后台无人值守。
- 同一套无障碍权限同时覆盖截图与输入注入，最省。

## 后果与风险
- 必须由被协助者在电视设置里手动启用一次第三方无障碍；部分国产定制系统（本项目的 TCL / 海信）可能限制或隐藏入口，**必须在真机验证**。
- 无 root 时无法给第三方 App 注入方向键 KeyEvent，因此采用“看画面点坐标”而非纯 D-pad 遥控。
- 需遵守无障碍权限的合规与用户知情：电视端可随时断开、拉黑。
